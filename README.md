# Mini Katalog App

Mini katalog uygulaması Flutter kullanılarak geliştirilmiştir. Bu uygulamada, ürünler bir katalog içerisinde kullanıcıya sunulur. Kullanıcılar ürün aratabilir, ürün özelliklerini görebilir ve sepete ürün ekleyip çıkarabilirler.

## Özellikler

- JSON dosyasından ürün verilerini okuma
- Ürünleri GridView ile listeleme
- Ürün arama
- Ürün detay arama
- Sayfalar arası Navigator ile geçiş
- Sepete ürün ekleme ve çıkarma
- Sepet durumunu state ile güncelleme
- Boş sepet ekranı
- Banner görseli kullanma

## Kullanılan Teknolojiler

- Flutter 3.41.6
- Dart 3.11.4
- Material Design

## Kurulum ve Çalıştırma

Projeyi bilgisayarınıza klonlayın:

```bash
git clone https://github.com/senaa04/sena-yolcu-mini-katalog-app.git
```

Proje klasörüne girin:

```bash
cd mini_katalog
```

Gerekli Flutter bağımlılıklarını yükleyin:

```bash
flutter pub get
```

Bir Android emulator veya fiziksel cihaz başlatın ve uygulamayı çalıştırın:

```bash
flutter run
```
